## 🧠 How I Approach Development

I'm a big believer in continuous learning, experimentation, and practical problem-solving.

I embrace AI-assisted development and regularly use tools like Claude Code, ChatGPT, and OpenAI Codex to accelerate the development process. I define the requirements, make architectural and design decisions, evaluate the results, troubleshoot problems, and take responsibility for the finished product.

Having worked with computers since the early days of personal computing, I see AI as another evolution in development tools, not a replacement for understanding what you're building.

Sometimes the best approach is to have an AI agent implement an entire feature. Other times, it's faster to open the editor and change a few lines myself. The goal isn't to use AI for everything. It's to use the right tools to build good software efficiently.

I enjoy working across the entire stack, from database design and backend APIs to user interfaces and Linux infrastructure.

I'm particularly interested in the intersection of **open technologies, self-hosted AI, and independent software development**.
